# 具身智能、世界模型与视频生成学习指南

这三个方向可以用三个问题来理解：**机器人该做什么？做了之后会发生什么？未来的画面怎样生成？**

这里把学习过程排成九章。每章都有正文、指定资料、练习和完成标准；先学会一个小问题，再去读对应论文。

**第一次来：打开 [从这里开始](学习指南/从这里开始.md)，按里面的步骤完成今天的一小时。**

## 读一章时，就做这四件事

1. 先看章节开头的步骤，知道这次要解决什么。
2. 读正文；不懂的词查 [术语速查](学习指南/术语速查.md)。
3. 按指定范围读一两份外部资料，再做本章的关键练习。
4. 对照完成标准，写下自己的解释，然后点“下一章”。

第一遍先做章节开头指定的练习。正文里的更多练习、选读和研究问题，可以回头补。电脑暂时不能运行代码时，先完成手算与阅读，准备环境后再补实验。

## 需要时再打开

- 想安排时间：[24 周安排](学习指南/24周安排.md)。按每周约 8 小时规划，可以放慢；不会 Python 先补预备课。
- 准备运行代码：[准备电脑](学习指南/准备电脑.md)。基础练习和三个专题实验用 CPU 即可。
- 只深入一个方向：[专题学习](学习指南/专题学习.md)；完成基础后再看 [深入研究](学习指南/深入研究.md)。
- 找更多资料：[资料库](学习指南/资料库.md)；找某一期可lip：[资料对应表](学习指南/可lip资料对应表.md)。
- 卡住了：[常见问题](学习指南/常见问题.md)；找某份文件：[完整目录](学习指南/完整目录.md)。

本课程的基础练习用于理解机制。完整视频模型、完整机器人策略和真实硬件实验需要额外准备，是否运行及验证范围见 [验证记录](学习指南/验证记录.md)。
