# Repository guidance

This is an original Chinese learning curriculum, not a mirror of third-party materials.

- Keep modules progressive: prerequisites, explained concepts, ordered resources, exercises, artifacts, acceptance criteria, limitations.
- Use primary papers and official projects/docs/courses. Cite the source supporting each technical or performance claim.
- Preserve distinctions among toy mechanisms, upstream code running, paper-result replication, ablation, simulation, and real robots.
- Do not copy third-party decks/media/long text into the repository.
- Do not commit credentials, personal notes, datasets, checkpoints, transient outputs, or .build files.
- Run python scripts/validate_repo.py --run-labs before publishing curriculum or experiment changes.
- Update source verification notes honestly and use the date actually checked.
- User instructions take priority. Windows commands should use Git Bash explicitly.
