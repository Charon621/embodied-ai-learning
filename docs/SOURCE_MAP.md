## 补充的必需内容

1. M01/M02补数学、代码训练循环、视觉和Transformer，避免每篇论文都重新追前置。
2. M03/M05补坐标、控制、MDP、BC/DAgger、ACT与Diffusion Policy；按问题比较动作表示。
3. M04/M08补DDPM/score、ODE、VAE/DiT、视频结构和生成评测。
4. M06/M07补训练时想象与测试时规划，分开表征/视觉质量/闭环证据。
5. M09与研究计划补控制变量、数据泄漏、种子、成本和否证。

原仓库的作者实测脚本和部分运行记录未公开，技术事实核查中已有说明。本课程不把那些成绩认领为自己的复现。原仓库是中文直觉辅助，必读链仍回原论文或官方教程；后续新型号优先进入选读，保持基础主线稳定。
