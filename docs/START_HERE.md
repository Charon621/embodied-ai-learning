# 从这里开始

这套课程面向想理解机器人如何从数据学动作、模型怎样预测世界、视频怎样生成的学习者。现成课程文件可直接在GitHub阅读；先不下载数据集和权重。

## 15分钟确定起点

不查答案，完成下表。自测通过允许跳过基础阅读，但还需能展示产物。没有基础也有明确补课入口。

| 自测题 | 通过标准 | 失败时补哪里 |
|---|---|---|
| 用Python读10个数字并算均值 | 能自己运行、处理错误、核对结果 | M01前置 |
| 写出矩阵乘法后的形状 | [N,d]×[d,1]得到[N,1] | M01第一课 |
| 推导平方损失对w的导数 | 有链式法则且符号正确 | M01第二课 |
| 区分train/eval与no_grad | 层行为与梯度图分别解释 | M01第四课 |
| 手算一次注意力 | softmax权重和1，Y形状正确 | M02 |
| 区分观测、状态和动作 | 能为一个机器人举例和写单位 | M03 |
| 解释BC误差为何可能累积 | 策略改变访问状态，离线误差不够 | M05 |
| 区分预测误差和任务成功率 | 举出好预测却没收益的可能例子 | M06/M09 |

不要根据记住模型名称给自己跳级。已有某项外部课程或工作经验，可以用产物证明等价前置，然后跳相应模块。

## 第一天只做三件事

1. 阅读[路线图](ROADMAP.md)，选择想深入的分支；希望完整覆盖则按24周计划。
2. 检查[环境](ENVIRONMENT.md)，运行实验01，打开输出CSV和SVG。还没学M05时，只记录“同分布动作误差小却可能闭环失败”这一现象。
3. 将[学习记录模板](../templates/learning-progress.md)复制到忽略的 `my-progress/`，写下起点、每周可投入时数与一个想解决的任务。

新手默认从M01开始；数学/训练循环熟练者先做M02；已有视觉与机器人学习基础者做M04/M05自测。GPU不是起步条件。

## 三条方向如何选

- **机器人策略方向**：M01→M02→M03→M04→M05→M09，完成BC对照和一个数据协议卡，再选研究进阶A。
- **世界模型方向**：在上述基础上M06→M08前半→M07→M09，完成预测与滚动规划，再选进阶B。已有BC与MDP基础可用自测替代M05部分。
- **视频生成方向**：M01→M02→M04→M08→M09，完成速度场与采样收敛实验，再选进阶C。机器人控制模块可后补；若研究WAM则必须回M03/M05/M06。

路线只减少与你当前目标无关的阅读，不取消算法需要的前置。完整主线建议依次M01、M02、M03、M04、M05、M06、M08、M07、M09。

## 每周8小时怎样分

2小时核心解释，2小时必读指定章节，3小时练习与记录，1小时复盘和验收。阅读量增加时先缩选读，不把练习全删掉。卡住两周时，把问题拆成一个公式、一个接口或一条可运行命令。

## 今天的完成标准

你知道从哪个模块开始；明确CPU能完成什么；运行或手算了一个最小例子；保存了个人进度；没有把“看过资料”计为“已掌握”。现在打开[本周计划](WEEKLY_PLAN.md)。
