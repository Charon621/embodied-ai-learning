# M04｜扩散与 Flow Matching：先学会运输一个分布

本模块建议投入 24–36 小时，时间是教学估计。核心问题是：怎样从容易采样的噪声，得到符合数据分布的新样本？完成后可进入 M08 视频生成，也可回到 M05 理解动作序列生成。先把概率路径、训练目标、网络结构和采样器分清，再读具体模型。

## 前置、自测与可测目标

前置：[M01](01-math-and-deep-learning.md) 的高斯分布、条件期望、梯度与最小二乘；[M02](02-vision-and-transformers.md) 的 Transformer、注意力与条件注入。ODE 与 Euler 法在本模块第 2 节学习，不要求提前掌握。不要求先学机器人。自测：若独立的 `X0 ~ N(0,1)`、`X1 ~ N(2,0.25)`，求 `Xt=(1-t)X0+tX1` 的均值和方差；解释为什么最小化平方误差得到条件均值；求标量平方误差 `(prediction-target)²` 对 `prediction` 的导数。三题至少两题能独立完成，剩余题能订正再开始。

学完必须能：① 从 DDPM 的加噪公式写出一条噪声预测训练样本；② 用一张表区分 score、噪声、速度及其时间方向；③ 推导玩具高斯路径的边缘速度；④ 运行 CPU 实验，分别报告学习误差和积分误差；⑤ 在一篇新论文里定位表示、骨干、目标、条件和采样器。只会说“逐步去噪”不算通过。

## 1. DDPM：训练时知道噪声，生成时预测噪声

DDPM 先定义数据到噪声的随机过程。每一步加入少量高斯噪声，而任意时刻都可以直接采样：

$$x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon,\qquad \epsilon\sim\mathcal N(0,I).$$

这里 `x0` 是数据，`t` 是噪声等级，`bar_alpha` 由预先选好的噪声日程决定。训练抽一个数据、一个时刻和一份噪声，让网络预测 `epsilon`，计算预测与真实噪声的均方误差。生成时没有真实数据可用，因而从噪声开始，利用网络估计反向转换；反向采样中的随机性和步长由具体采样方案决定。

把“预测噪声”理解成一个可训练的参数化，不要理解成给图像打标签。网络也可以预测干净样本或其他变量，但转换公式、损失权重与噪声日程需要一致。看见两个模型都用了 MSE，不能断言它们训练等价。先读 [DDPM 作者项目页与论文（V-01）](https://hojonathanho.github.io/diffusion/)，关注训练、采样算法和符号，不以当年排行榜数字作为学习目标。

做一个手算例子：干净数据为三，累计保留系数为零点六四，抽到的噪声为负一；中间样本就是一点八。假设网络输出负零点八，这个样本的噪声平方误差为零点零四。训练者知道答案，是因为噪声由自己抽取；生成时只有当前状态和模型预测。这个差别说明为什么训练可以一次抽取任意时刻，推理仍然需要逐步构造样本。再尝试由预测噪声解出干净样本估计，检查保留系数趋近零时误差为何容易放大。

## 2. Score、SDE 和 ODE：相关，但不在同一个层级

Score 是 `s_t(x)=∇x log p_t(x)`，表示密度在当前位置增长最快的方向；它不是分类置信分。在高斯加噪条件下，噪声预测可按相应尺度转换成 score。离散扩散可以联系到连续时间描述，但连续化的噪声日程必须写清楚。

先补齐一个最小 ODE 例子。`dx/dt=v(x,t)` 表示位置的瞬时变化率由速度场给定；已知初始位置，就沿这个变化率寻找后续轨迹。Euler 法把当前速度在一个小时间段内近似为不变：`x_next=x+h*v(x,t)`，再把时间更新为 `t+h`。它只需要会代入和乘加，无须先修微分方程课程。

取 `dx/dt=x`、`x(0)=1`，走到 `t=1`。用两步、每步 `h=0.5`：第一步得到 `1+0.5×1=1.5`，第二步得到 `1.5+0.5×1.5=2.25`。解析终点为 `e≈2.71828`，误差约 `0.46828`。改用四步，结果为 `1.25⁴≈2.44141`，误差约 `0.27688`。误差来自每步忽略了段内速度变化；对足够光滑且满足适当稳定条件的场，固定时间区间上的 Euler 全局误差通常为步长的一阶。继续减小步长能改进积分，却不能修复模型学错的速度。现在自行算八步，并比较误差，再进入实验中的学习场与解析场对照。

SDE 写成 `dx=f(x,t)dt+g(t)dW`，描述带随机扰动的演化。Score SDE 框架的反向漂移含有 `f-g²s`，此处沿时间从大到小积分，`dt` 为负，不能把公式直接套进正向更新。对应的 probability-flow ODE 使用 `f-½g²s`，没有布朗噪声。精确 score 和合适数学条件下，二者有相同的各时刻边缘分布；它们的单条轨迹与数值误差并不相同。学习到的近似 score 也不保证实际输出完全一致。参见 [Score SDE（V-02）](https://arxiv.org/abs/2011.13456v2)。

因此，DDPM 是一类离散建模方法，score 是待估计的量，SDE/ODE 是演化方程，Euler 是数值求解器。它们不能放在同一列作为互斥的模型名称。阅读时始终标注“训练输出是什么”和“生成沿哪个方向走”。

## 3. Flow Matching：监督局部速度，采样时再积分

为便于理解，这一节改用噪声到数据的时间方向：`t=0` 是噪声，`t=1` 是数据。独立采样两个端点，定义直线条件路径 `xt=(1-t)x0+t x1`，已知该路径的速度 `u=x1-x0`。训练网络输入 `(xt,t)`，回归这个速度。训练时直接构造中间状态，不必运行整个 ODE；生成时仍要从噪声积分学到的速度场。Flow Matching 原论文允许更一般的条件概率路径，直线只是本课例子。[Flow Matching（V-03）](https://arxiv.org/abs/2210.02747v2)

关键一步：不同端点对可能经过同一个 `(x,t)`，它们的速度不同。MSE 学到的是 `E[u|Xt=x]`，并非记住每条配对直线。独立随机配对也不能直接称为全局最优运输。对于本课高斯例子，令 `μ=2`、`σ=0.5`：

$$m_t=t\mu,\quad q_t=(1-t)^2+t^2\sigma^2,$$
$$v(x,t)=\mu+\frac{t\sigma^2-(1-t)}{q_t}(x-t\mu).$$

中间方差先收缩再变化，因此边缘速度场不是始终恒定。训练损失包含条件速度的不可约方差，不会因学到正确边缘速度就降到零。这个推导正是实验验收所需的概念关卡。

代入中点，均值是一，方差为零点三一二五，速度为“三点二减去一点二乘位置”。处在均值位置的粒子速度为二；更靠左的粒子更快向右，因而分布在这一阶段收缩。它与把每个噪声点直接平移两个单位不同，后者保留标准差为一，无法得到目标标准差为零点五。用这两个方案作对照，就能看出“均值正确”为什么不足以证明学到了分布。还应检查方差和分布形状；高斯例子中这两项较简单，多峰数据则更容易暴露模型能力不足。

## 4. Latent 与 DiT：改变表示和骨干，保留问题分层

像素空间状态很大，可以先用编码器压缩，再在 latent 中训练生成模型，最后用解码器还原。VAE 类表示通常在重建与潜变量正则之间做权衡；压缩有损，若小物体或细节在编码阶段丢失，后续生成器不能凭空保证恢复。Latent diffusion 是生成所在的空间选择，不是 Flow Matching 的反义词。参见 [LDM（V-04）](https://arxiv.org/abs/2112.10752v2)。

DiT 将 latent 切成 patch token，使用 Transformer 作为生成网络骨干。时间与其他条件可以通过 AdaLN 等机制调制特征；文本也可以作为注意力条件。AdaLN 不是生成目标，位置编码也不是采样器。减小 patch 会增加 token，计算代价必须跟着重算。读 [DiT 作者项目页（V-05）](https://www.wpeebles.com/DiT) 后，为一个假设系统写五行：VAE 表示、Transformer 骨干、速度/噪声目标、文本条件、ODE/其他采样器。若能独立替换其中一行，说明你真正分清了层级。

## 5. 条件和采样：把“更符合提示”与“更准确”分开

条件可以是类别、文本、图像、动作或轨迹。Classifier-free guidance（CFG）在训练时让模型也能处理无条件输入，采样时组合有条件与无条件预测。一种常见记号是 `pred=uncond+s*(cond-uncond)`；不同实现可能采用不同的 `s` 定义，比较前要核对。引导强度变化可能改变提示符合度、细节与多样性，不能把它解释成概率校准。[CFG（V-06）](https://arxiv.org/abs/2207.12598)

采样步数减少，会降低网络调用成本，也可能增加积分误差；更多步数并不能修复错误的速度场、数据偏差或解码器损失。比较采样器时固定初始噪声、条件和模型，同时记录调用次数、步长日程与输出。先做可解释的一维实验，之后再迁移到高维。

## 低算力替代、误区与进阶问题

本实验 CPU 即可完成，无数据、权重下载或 API 调用。进一步缩减训练样本时保留独立验证，允许验收失败并解释抽样误差；不要只报告最好种子。无编程条件可手算 `t=0,0.5,1` 的速度及两步积分，产物相同但注明未运行。

常见误区：把 ODE 等同于 Flow Matching；把 latent 当作另一种损失；把低训练 MSE 当作高生成质量；沿错时间方向积分；把随机配对直线当成学到的粒子轨迹。进阶：若目标变成双峰分布，仿射场为何不足？如何换成非线性场并保留独立检验？同一个端点误差能否区分模型偏差与离散误差？换概率路径时如何重新推导目标？
