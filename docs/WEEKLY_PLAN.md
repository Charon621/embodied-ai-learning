# 24周主线计划

每周8小时，合计192小时。已有基础可按自测压缩；没有编程基础先加1–2周前置。每周的产物比阅读页数重要。建议留出额外缓冲。

| 3 | 概率、分布、条件均值 | 采样实验与双峰动作解释 |

## 结业检查

- 9个模块的自测和练习有产物，或有等价前置证明。
- 能画VLA、latent WM、视频生成与WAM的不同输入输出。
- 3个CPU实验至少都读懂并执行一次；结业项目对其中一个做3种子受控扩展。
- 指标、分母、数据划分、版本和成本可回查。
- 报告包含失败、反例和未验证边界，别人能按命令重跑。

## 时间不足时

每周4小时可将每个教学周拆成2周；每周12小时可缩短阅读，但仍按验收推进。先跳选读与完整GPU复现，保留练习。专项分支按[入门页](START_HERE.md)只做相应模块，再进入研究进阶。研究论文和模型更新不用塞进主线每周，集中到进阶阶段刷新。
