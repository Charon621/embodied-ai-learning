# 研究进阶：用12周深入一个问题

前置：完成主线或专项分支的验收；能独立读训练循环、控制/采样接口，并知道自己还没复现什么。12周×每周8小时约96小时是一次小研究的计划预算，完整论文结果复现可能更长。只选A/B/C一条，先机制，后真实规模。

## 进入研究前的五项能力

1. 推导选定方法的训练目标，标出采样分布、监督变量和停止梯度的位置。
2. 画出训练与推理两套数据流，解释它们为何不同。
3. 从官方代码定位数据loader、核心forward、loss、采样/控制循环与评测入口。
4. 为原论文的一张关键表复原划分、预算、输入和指标定义。
5. 写一个会推翻自己假设的实验，并保留原始输出。

不能完成时，先回对应模块，不以“再看一篇综述”替代缺失能力。

## A 机器人策略：覆盖、动作表示与闭环

**问题A1**：反馈采样的收益究竟来自覆盖范围还是采样策略？在lab01中比较窄分布BC、等标签数量的广覆盖离线BC、反馈查询BC。先固定特征类、ridge、标签噪声、初始状态集合和总标签预算。由于toy的专家可查询，这是机制实验；真机专家查询成本完全不同。

**问题A2**：同一观测的左右两种动作，均值回归与分布建模各会怎样？先构造有显式双峰的二维绕障问题，报告碰撞、终点误差和样本多样性，不能只看动作MSE。再选择ACT或Diffusion Policy的官方小任务作为可选扩展。

必做推导：BC经验风险与访问分布的区别；分块动作的执行频率和更新频率；平方损失为什么偏向条件均值。不要把动作token和文本语义等同。

精读顺序：[DAgger](https://proceedings.mlr.press/v15/ross11a.html)→[ACT](https://arxiv.org/abs/2304.13705)→[Diffusion Policy](https://arxiv.org/abs/2303.04137)。VLA则从[OpenVLA](https://arxiv.org/abs/2406.09246)的接口和数据混合，再读[π0](https://arxiv.org/abs/2410.24164)的连续动作训练。各资源具体读法见M05，完整版模型不要求从头预训练。

产物：等预算数据比较表、动作/频率/schema卡、全部rollout结果、至少一个失败例子。GPU扩展需锁定同一数据集与任务，不能把官方旧成绩和你的新协议混表。

## B 世界模型：模型误差与规划是否同向

**问题B1**：小的一步误差能否预测长程闭环表现？在lab03中先检查holdout是否位于训练支持内，再比较一步、多步、开环和滚动规划。现有脚本用确定性坐标下降求动作，没有采样动作候选。其 `--horizon` 同时改变整局长度、终端代价位置和冲击时刻，自由预测仍固定到20步，直接扫描它会混淆变量。

研究规划范围前，先扩展代码，把 `planning_horizon` 与固定的 `control_steps` 拆开，并固定冲击时刻、真实评测代价定义、模型类、训练数据和优化预算；在滚动控制器里只改变规划范围，另记每次求解残差与计算量。还要新增模型内预测代价记录，才能统计真实与预测代价的差值。暂不改代码时，使用现有四情景作预测/控制审计，明确开环与滚动调用数不同，不作同计算预算的归因。

**问题B2**：减少与任务无关的预测负担，是否损失对控制关键细节的敏感性？从有干扰背景的低维合成环境起步，构造像素/任务相关表征两种预测目标。先说明“任务相关”如何定义，避免用测试标签设计表征。

必做推导：RSSM的确定与随机状态各保存什么；KL与重建/奖励等损失的角色；模型内训练actor与测试时MPC的梯度路径；单步误差通过rollout累积的可能机制。不能假设模型内部latent有真实标签。

精读顺序：[PlaNet](https://arxiv.org/abs/1811.04551)→[Dreamer](https://arxiv.org/abs/1912.01603)→[V-JEPA 2](https://arxiv.org/abs/2506.09985)。从[M06](modules/06-latent-world-models.md)找模型与计划细节；对视频预测/联合动作有兴趣再进入M07。

产物：horizon×模型扰动的误差/控制二维表、计算成本、真实和预测轨迹、失败归因。学习到的动力学与人为偏置必须分别记录，不能把不匹配都叫分布外泛化。

## C 视频生成：估计误差、采样误差与可控性

**问题C1**：增加采样步数是否总能改善结果？在lab02固定学到的场，测解析场积分误差与学到场误差，找收益停止的范围。再降低训练样本量；不能把细化积分当成修复错误场。

**问题C2**：更好的单帧画质是否伴随更好的时序和条件执行？选择一个实际可运行的官方视频模型，固定版本、prompt集、分辨率、帧数、种子和生成预算，分别评价画质、时序、文本匹配与失败。无法运行时先对公开协议写审计报告，不伪造结果。

必做推导：DDPM的噪声预测与score联系；Flow Matching条件目标与边缘速度场；ODE采样和训练回归为何不同；VAE压缩、patch化和attention预算。视频生成拟合分布不自动获得动作条件的物理因果模型。

精读顺序：[DDPM](https://arxiv.org/abs/2006.11239)→[Flow Matching](https://arxiv.org/abs/2210.02747)→[DiT](https://arxiv.org/abs/2212.09748)→[Video Diffusion Models](https://arxiv.org/abs/2204.03458)。完整视频模型与评测入口见[M08](modules/08-video-generation.md)；不以最新型号作理论前置。

产物：步数×训练量/误差表、明确prompt和采样协议、全样本索引、失败分类。只呈现最佳视频不能通过验收。

## 12周施工表

| 周 | 工作 | 停止/继续条件 |
|---|---|---|
| 1 | 选一个问题，做前置自测 | 输入输出和指标说不清则补课 |
| 2 | 读3篇关键论文，做证据卡 | 关键表版本或协议未知则标未知 |
| 3 | 官方代码定位或toy基线重建 | 必须出现可复跑的基线 |
| 4 | 数据支持与划分审计 | 泄漏未解决不开始对照 |
| 5 | 定义单一变化，写预案 | 自变量和成本不能混淆 |
| 6–7 | 运行全部种子与对照 | 预算超限先缩任务/规模 |
| 8 | 消融与至少一个反例 | 没有反例尝试不扩结论 |
| 9 | 分布外或新任务验证 | 使用独立数据，保留失败 |
| 10 | 统计、成本和替代解释 | 小样本结论加限定 |
| 11 | 从干净环境复跑 | 不能复跑则优先修记录 |
| 12 | 报告、代码和下一步 | 最窄结论+未验证边界齐全 |

进入真实机器人前，另外按实验室操作规范检查硬件、控制限幅与停机，课程toy不能替代设备流程。未具备条件时留在仿真或离线研究。

## 毕业标准

用[研究报告模板](../templates/experiment-report.md)回答一个可证伪问题；每个性能说法有数据、版本、协议和成本；别人能复跑关键结果；失败不删；知道哪些收益可能来自额外数据、容量或预算。发表与真正掌握需要持续积累，12周只是一个可审查的研究循环。
