## 开始之前

能用函数、循环和列表写一个程序，能在命令行运行它，并区分文件路径与工作目录。不会编程者先补 [Python 官方教程](https://docs.python.org/3/tutorial/) 第 3–8 章；该教程面向已懂一点编程的人，可先用下面的最小任务自测：

写函数读取一个含 10 个数字的 CSV，返回均值、方差和最大值；为不存在的文件给出错误信息。结果用手工计算的三个数字交叉核对。尚不能完成时，先花 1–2 周练习函数、列表、字典、文件和异常，暂缓阅读模型论文。

## 完成后能做什么

能把观测写成张量形状，推导线性回归的梯度，区分参数和数据，说明训练/验证/测试的用途，并检查模型在没见过的数据上是否有效。还要能解释“采样一次”和“求期望”的差别。

## 第一课：从数据对象到线性代数

先认识标量、向量、矩阵和批次维。一个 RGB 图像可以用 `[H,W,3]` 表示；PyTorch 常用 `[B,3,H,W]`。两者都是约定，算法不能替你发现通道顺序错误。

点积是对应项乘积再求和，矩阵乘法把这件事批量进行。对于 X 为 `[N,d]`、w 为 `[d,1]`，Xw 为 `[N,1]`；N 是样本数，d 是每个样本的特征维。转置、广播和 reshape 改变的是不同东西。特别注意：reshape 不会把“每张图的像素”自动变成正确的“每个像素的通道”。

先做 2×3 与 3×2 矩阵手算，再在程序中核对。理解坐标变换之前，只需补矩阵乘法和逆；理解概率模型之前，补方差、协方差和正定矩阵。不要等整本数学书读完才开始实验。[数学书作者官网](https://mml-book.com/) 第 2、5–7 章提供查漏入口。

## 第二课：学习等于定义损失并改变参数

用最小问题 y≈wx+b 开始。平方损失 L=(1/N)Σ(wx_i+b−y_i)²，其梯度为：

```text
dL/dw = (2/N) Σ (wx_i+b−y_i)x_i
dL/db = (2/N) Σ (wx_i+b−y_i)
w <- w − learning_rate * dL/dw
```

这三行包含数据、模型、目标和优化。训练标签不是“答案生成器”输出的自然事实，而是你对任务的定义。若把所有时间步拆散再随机分组，相邻帧可能同时进入训练与测试，误差会过分乐观。

先用有限差分 [L(w+ε)−L(w−ε)]/(2ε) 核对手算梯度，再理解自动微分怎样沿计算图应用链式法则。学习率过大会震荡，过小会学得慢；验证误差上升时，训练误差继续下降也不等于能力继续提升。[CS231n 优化笔记](https://cs231n.github.io/optimization-1/) 用图解释梯度和数值检查。

## 第三课：概率与不确定性

高斯分布的均值决定中心，标准差决定扩散程度。条件分布 p(a|o) 描述给定观测下可能的动作，不等于每个动作都有唯一正确标签。如果同一画面可以从左右绕开障碍，平方损失会倾向预测平均动作，而平均动作可能正撞上障碍。这会连接到 第4章 的生成式模型和 第5章 的多模态动作。

分别解释样本均值、总体期望、模型概率、测量噪声和缺失信息。softmax 归一化输出只保证各项和为 1，不保证它与事件频率一致。后续模型的“confidence”需单独查定义，不能当作校准概率。

练习固定随机种子采 100、1,000、10,000 个高斯数，每组报告均值与标准差。固定种子帮助复现一次实验；多个种子帮助判断结果是否偶然。

## 第四课：PyTorch 的训练循环

读 [Learn the Basics](https://docs.pytorch.org/tutorials/beginner/basics/intro.html) 的 Tensors、Datasets、Build Model、Autograd、Optimization 和 Save/Load。自己标出：

```text
取 batch -> forward -> loss -> zero_grad -> backward -> step
验证：eval + no_grad -> 与训练不同的样本 -> 聚合指标
```

`train()/eval()` 控制部分层的行为，`no_grad()` 控制是否建梯度图；这两件事不能互相替代。checkpoint 保存参数；实验记录还要保存配置、数据划分、版本和种子。

本仓库三个入门实验仅需 Python 标准库。PyTorch 练习是扩展，按 [官方安装选择器](https://docs.pytorch.org/get-started/locally/) 选择 CPU 或与实际驱动匹配的版本，在独立环境安装；不要照抄某台机器的 CUDA 命令。

## 动手练习与完成标准

A. 用标准库从零拟合 y=2x−1 的 100 个带噪声样本。先分组再训练，保存拟合系数、训练/留出误差及学习率。至少对 3 个初始参数重复，解释哪次没收敛；不要用测试集选择学习率。

B. 把三条相邻 episode 的时间步拆散随机划分，再按 episode 整体划分。画出两个方案的归属表，解释为何前者泄漏。真实机器人数据还可能需要按房间、任务、人员、机器人或时间批次分组。

C. 写一页“训练循环诊断卡”：标签错位、梯度没清零、归一化统计量用了测试集、只报告最好种子，各会产生什么假象，怎样定位。

过关：手推上述两个梯度；有限差分相对误差低于 1e−4（避开几乎为零的梯度）；能在没看答案时解释训练/验证/测试；能发现至少一个分组泄漏。该数值阈值只用于简单算例。

## 低算力路线与进阶

没有 GPU 时，上述推导和标准库实验仍可完成；PyTorch 用很小的合成数据与 MLP。不要把高分辨率视觉训练作为前置。

进阶可推最大似然与平方损失的关系、正则化的偏差/方差，以及条件分布是双峰时均值预测为何失败。遇到优化推导先回 第1章，不要通过更换模型掩盖数据错误。
