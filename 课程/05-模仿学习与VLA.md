# 第5章：模仿学习与VLA

[课程首页](../README.md) · [上一章](04-扩散与FlowMatching.md) · [下一章](06-世界模型与规划.md)

从示范学动作，为什么仍会在执行中失败；语言与视觉怎样接入策略。

## 这一章怎么学

1. **先做的事**：先做 [行为克隆实验](../练习/行为克隆怎么做.md)，再读动作块、生成动作和 VLA。
2. **再读的资料**：先读正文的 BC/DAgger，再读 [OpenVLA](https://openvla.github.io/) 与 [π0](https://arxiv.org/abs/2410.24164)；更细的论文范围见本章阅读表。
3. **可以继续的标准**：能解释示范覆盖与闭环失败，画出观测/指令到动作的流程，说明反馈查询增加了数据。

主线参考用时：24小时。第一遍先完成上面的关键练习；正文中的其他练习和选读可回头补。遇到术语先查 [速查页](../学习指南/术语速查.md)。

## 正文讲解

目标是读懂“机器人怎样学会输出动作”，并能发现一项结果究竟依赖数据、动作表示还是控制协议。建议 **20–28 小时，主线约 24 小时**，时间为教学估计。先完成 [第2章 视觉与 Transformer](02-视觉与Transformer.md)、[第3章 机器人基础](03-机器人与控制.md)、[第4章 扩散与 Flow Matching](04-扩散与FlowMatching.md)。

## 开始之前

自测：能否解释条件概率 `p(a|o)`、注意力的输入/输出形状、噪声时间与机器人执行时间的区别、动作的坐标和单位？其中任何一项不清楚，回前面的相关章节做一个小例子。

完成后应能：推导平方误差为什么会平均多峰动作；解释 BC 的闭环分布偏移与 DAgger 的数据收集逻辑；区分 ACT 分块、Diffusion Policy 去噪和 π0 的 Flow Matching；画出 RT-2/OpenVLA/π0 的动作输出路径；写出与模型能力主张匹配的评测协议。

## 1. 行为克隆：先把示教变成条件预测

行为克隆（BC）从专家数据学习 `πθ(a|o)`。若输出确定性连续动作，可最小化示教动作与预测动作的误差；若输出离散动作 token，可最小化负对数似然。输入可以含图像、机器人状态与指令，训练仍然依赖示教标签。模型使用 Transformer 或生成式动作头，并不自动意味着用了强化学习。

首先处理**多峰**：同一障碍物可以左绕或右绕，示教动作分别为 `−1` 与 `+1`。等概率、平方误差回归的最优预测是 0，可能恰好撞上障碍物。问题在于输出分布能否保留可行策略，而不只是模型够不够大。

再处理**分布偏移**：训练样本来自专家访问的观测，部署观测来自学习者自己行动的结果。一点错误可能让机器人偏离示教状态，后续又遇到没学过的输入。离线单步误差无法完整衡量这种累积。[DAgger 原论文](https://proceedings.mlr.press/v15/ross11a.html) 的办法是让当前策略访问环境，请专家标注这些访问状态的正确动作，把新数据与旧数据汇集，再训练。它需要专家查询与交互条件；不能把“多训练几轮原数据”称作 DAgger，也不能认为它无条件保证真机安全。

## 2. ACT：把一个动作扩展为连贯的一段

[ACT 原论文 v1](https://arxiv.org/html/2304.13705v1) 让策略预测未来一段动作，称为 action chunk。训练使用条件 VAE：编码器从示教动作和关节观测提取潜变量，解码器结合图像、关节状态与潜变量生成动作序列；推理不再使用看见未来示教的编码器，而使用先验均值。要分清训练时可用信息和部署时可用信息。

分块帮助学习局部连贯的动作，也缩短逐次决策的有效序列长度；它不会消除接触误差或没见过的场景。预测长度与实际执行长度需要分别设定。ACT 的时间集成针对**同一个未来时刻**，合并不同起点预测出的重叠动作；这不同于把相邻时刻的动作简单平均。原论文中动作是 leader 的目标关节位置，由 follower 的低层控制器跟踪，不能直接替换成末端增量而不改接口。

## 3. Diffusion Policy：在动作空间生成，不必先生成未来视频

将 第4章 的条件扩散迁移到动作：用观测作为条件，把未来动作序列加噪，训练网络预测去噪方向；推理从噪声逐步生成动作。它建模 `p(A_t|O_t)`，可以表达多种动作方案。一次采样要形成连贯方案，不能在执行中无规则切换绕行方向。[Diffusion Policy 原论文 v4](https://arxiv.org/html/2303.04137v4)

记住三个窗口：观测长度 `T_o`、预测长度 `T_p`、实际执行长度 `T_a`。例如自定义练习取 `T_o=2、T_p=8、T_a=2`：看最近两次观测，生成八个动作，只执行前两个，然后重新观察和预测。滚动执行让序列连贯与反馈响应取得平衡；更长的执行段也会更久不看新观测。这三个数是教学例子，不是推荐真机配置。

去噪迭代发生在一次推理内部，机器人执行发生在物理时间上。增加去噪步骤不等于增加控制频率。Diffusion Policy 仍会受示教覆盖限制，生成式输出解决的是动作分布表示，不能独自解决 BC 的分布偏移。

## 4. VLA：复用语义知识，再解决动作如何表达

VLA 将图像、指令与动作连接起来，但比较时必须拆开视觉编码、语言主干、动作头和数据。

| 路线 | 读懂的关键 | 必须检查的接口 |
|---|---|---|
| [RT-2](https://robotics-transformer2.github.io/) | 把机器人动作表示为文本 token，与视觉语言任务共同训练 | token 如何还原成动作，量化、尺度与坐标 |
| [原始 OpenVLA](https://openvla.github.io/) | 视觉编码器与语言主干输出 token 化动作，提供开放训练与权重入口 | 预处理、动作归一化、具体机器人数据键 |
| [π0 原论文 v1](https://arxiv.org/html/2410.24164v1) | 预训练 VLM 与动作专家结合，用 Flow Matching 生成连续动作段 | 本体状态、动作长度、连续积分与执行节奏 |

这里比较的是指定版本的基本机制，不能把后来同名项目的改进配置混入原始模型。π0 与 Diffusion Policy 都可生成连续动作段，但训练路径、动作网络和预训练方式不同；RT-2/OpenVLA 的 token 路线也不是“落后的语言模型”。动作表示要服务于精度、延迟、数据与部署条件。[OpenVLA 官方模型说明](https://openvla.github.io/)、[π0 模型章节](https://arxiv.org/html/2410.24164v1)

“理解杯子”与“成功抓杯子”之间还隔着视角、接触、控制与示教覆盖。跨本体数据让迁移成为可能，却要求明确动作约定和适配器。π0 的预训练与面向下游任务的后训练也应分别检查，不能将特定任务后训练的结果当作未适配泛化。

## 5. 数据与评测：把主张翻译成可检验的问题

沿用 第3章 数据卡，额外注明示教采集方式、失败数据是否保留、语言标注粒度、训练混合比例和动作段截取方式。先划分数据，再拟合统计；动作序列窗口不能跨 episode，也不能偷偷读取部署时未知的未来图像。

用 [LIBERO 官方接口](https://github.com/Lifelong-Robot-Learning/LIBERO) 构造评测时，至少冻结套件/任务、初始状态、模型与软件版本、图像预处理、动作反归一化、最大步数及成功判定。比较两种策略用同一组任务和初始状态，保留每局记录，再汇总成功比例与不确定性。不同论文的汇总数字若协议不同，不能直接得出普遍优劣。

扩展阅读 [π0.5 原论文](https://arxiv.org/abs/2504.16054)：关注异构任务共同训练和未见环境的实验设计。阅读 [openpi 官方代码](https://github.com/Physical-Intelligence/openpi) 时，先查模型配置、数据转换和归一化链路；实现支持与论文系统不能自动画等号。

## 动手练习与完成标准

1. **BC 与反馈数据（约 3 h）**：按 [实验 README](../labs/README.md) 运行 [标准库玩具实验](../labs/01_behavior_cloning.py)。读取 `training_range、ridge、bc_weights、feedback_weights、feedback_history`，观察窄训练覆盖与 ridge 正则化如何让二次项拟合不足，再比较同分布留出误差、分布外动作误差与整局表现。反馈收集既改变访问状态覆盖，也增加专家标签预算；把查询次数和原始标签数同时写入 `outputs/m05/bc-review.md`，附种子、一次失败轨迹与一个反例。若要将改善归因于交互采样策略，须另加**等总标签预算、覆盖较广状态的离线专家数据**对照，并对齐模型、正则化、标签噪声和评测起点；本脚本未提供该对照，因此结果只说明这组教学配置下反馈数据有帮助。验收：解释单步误差为何不足，明确这是教学反馈收集演示，**不是 DAgger 原论文或机器人系统复现**。
2. **动作多峰与分块（约 2 h）**：对标签 `[-1,+1]` 分别计算预测 `-1、0、+1` 的平均平方误差，说明 0 最优却可能不可行。再画 `T_p=8、T_a=2` 的前三次预测/执行时间表，列出同一时刻的重叠预测。保存 `outputs/m05/action-table.md`。验收：误差依次为 `2、1、2`；不混淆噪声时间、预测时刻与物理执行时刻；说明平均不同模式的动作也可能有问题。
3. **VLA 对照与评测合同（约 3 h）**：为 RT-2、原始 OpenVLA、π0 各写一张卡：观测、动作表示、训练目标、预训练来源、执行方式、局限；每个事实附官方链接。为“未见场景仍可完成抓放”写出留出方式、对照、初始状态、每局日志字段与失败归类。产物为 `outputs/m05/vla-cards.md` 和 `eval-contract.md`。验收：卡片能画出输入到动作的完整链路，协议能区分直接推理与任务适配，无跨协议排行榜结论。

## 低算力替代与可选完整实验

主线无需 GPU、机器人、外部数据或权重。CPU 实验、手算与官方代码阅读已足以检验关键理解。可选扩展：固定某一官方代码版本和 LIBERO 单一任务，用官方兼容权重先检查数据/动作接口，再逐局评测，最后考虑微调。完整 ACT、Diffusion Policy、OpenVLA 与 openpi 训练/推理**本课程未实测**。尤其 openpi 官方列出 GPU 和操作系统要求，Windows 阅读代码与 CPU 教学实验不能冒充其受支持部署；执行前查看当时的官方说明。

## 常见误区、完成与进阶

- 把动作生成等同于世界模型；把分块等同于完全开环；把扩散等同于自动纠错；把开放权重等同于硬件兼容；把特定任务微调结果说成直接泛化。
- 完整学习要求：完成三组练习，能用自己的例子说明多峰、分布偏移、动作段与协议四个问题；不能只复述模型名字。接着进入 [第6章 潜在世界模型](06-世界模型与规划.md)，比较“预测动作”和“预测行动后果”。
- 进阶问题：动作 token 的量化误差如何影响接触任务？预测段变长时，策略响应扰动会怎样变化？失败轨迹应如何利用？如何检验语言条件确实改变行为，而非模型只看场景猜任务？
