# 第一次打开，从这里开始

[回到课程首页](../README.md)

你现在只需要弄清一件事：**“学习模型”到底在学习什么？** 今天用一条直线来理解它。之后再进入图片、机器人和视频。

## 今天的一小时

### 先用十分钟，看清三个方向

想象桌上有一个杯子：

- **具身智能**：机器人看到杯子和“拿起来”的指令，决定机械臂与夹爪怎么动。
- **世界模型**：给定当前状态和一个动作，预测杯子或机器人接下来会怎样。
- **视频生成**：给定描述或首帧，生成后续画面。

这三个问题会共享视觉、生成模型等工具，输入和要检验的结果各有侧重。先记住这个例子即可，后面的章节逐步展开。

### 再用十五分钟，理解一个最小模型

有两条数据：`x=0 → y=-1`，`x=1 → y=1`。你能看出规律是 `y=2x-1`。

程序起初只知道 `预测值 = w*x+b`，不知道 `w=2、b=-1`。训练就是拿数据比较预测和真实值，一点点改变 `w、b`。**参数是要学的规律，数据是提供线索的例子。**

打开 [第一章](../课程/01-数学与深度学习.md)，先读“从数据对象到线性代数”和“学习等于定义损失并改变参数”。遇到矩阵暂时看不懂，先把一维直线例子做明白。

### 用二十五分钟，完成第一个练习

打开 [让程序学会一条直线](../练习/01-线性回归/README.md)。它给了手算、完整代码、运行命令和结果解释。

已有 Python 就按命令跑一次；暂时没有 Python，先做页面里的手算部分。准备本地环境时再打开 [准备电脑](准备电脑.md)。今天不需要下载模型、注册 API 或安装仿真器。

### 最后十分钟，留下三句话

在自己的笔记里回答：

1. `w、b` 和数据 `x、y` 有什么区别？
2. 误差变小代表了什么？为什么还要看没参加训练的数据？
3. 我现在最卡的是代码、数学，还是术语？

能用自己的话解释前两题，今天就完成了。接下来继续 [第一章](../课程/01-数学与深度学习.md)，按该章步骤学完再去第二章。
