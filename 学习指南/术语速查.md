# 遇到生词时查这里

[回到课程首页](../README.md)

先用一句话理解，再到相应章节展开。例子只是帮助理解，具体论文的术语以该论文定义为准。

| 词 | 可以先这样理解 | 在哪里学 |
|---|---|---|
| 参数 parameter | 模型要从数据学出的数，如直线的 w、b | [第一章](../课程/01-数学与深度学习.md) |
| 损失 loss | 训练中衡量预测与目标差多少的量 | 第一章 |
| 梯度 gradient | 参数小幅变化时，损失怎样变化 | 第一章 |
| batch | 一次更新使用的一组样本 | 第一章 |
| 过拟合 | 把训练数据学得很好，没见过的数据表现差 | 第一章 |
| 留出数据 holdout | 没有用于拟合的数据，用来检查学习结果 | 第一章 |
| 特征/表征 representation | 把原始输入变成适合后续任务的信息 | [第二章](../课程/02-视觉与Transformer.md) |
| token | 模型处理的序列元素，可以来自文字、图像块等 | 第二章 |
| attention | 一个元素根据权重读取其他元素的信息 | 第二章 |
| mask | 规定哪些位置的信息可以读取 | 第二章 |
| 观测 observation | 传感器能测到的信息，如相机图像 | [第三章](../课程/03-机器人与控制.md) |
| 状态 state | 描述环境并用于预测演化的信息，可能部分隐藏 | 第三章 |
| 策略 policy | 根据观测或状态选择动作的方法 | 第三章 |
| episode | 从开始到结束的一整条交互轨迹 | 第三章 |
| 闭环 | 执行动作后读取新观测，再调整行动 | 第三章 |
| 分布 distribution | 数据可能取哪些值，以及各自出现的规律 | [第一章](../课程/01-数学与深度学习.md) |
| 扩散 diffusion | 通过加噪与学到的反向过程生成样本的一类方法 | [第四章](../课程/04-扩散与FlowMatching.md) |
| Flow Matching | 学习随时间变化的速度场，用它运输分布 | 第四章 |
| 采样 sampling | 用已定义的分布或模型生成一次结果 | 第一、四章 |
| 行为克隆 BC | 用示范观测和动作，监督学习一个策略 | [第五章](../课程/05-模仿学习与VLA.md) |
| VLA | 将视觉、语言与动作连接起来的模型 | 第五章 |
| latent | 模型内部压缩后的表示，未必是真实物理状态 | [第六章](../课程/06-世界模型与规划.md) |
| rollout | 沿环境或模型连续展开多个时间步 | 第六章 |
| MPC/滚动规划 | 规划一串动作，先执行一部分，再观察和规划 | 第六章 |
| VAE | 一类压缩和重建数据的概率模型 | [第四章](../课程/04-扩散与FlowMatching.md) |
| DiT | 用 Transformer 作为扩散模型骨干的架构 | 第四章 |
| T2V/I2V | 根据文本/给定图像生成视频 | [第七章](../课程/07-视频生成.md) |
| WAM | 把世界预测与动作放入同一模型的研究方向 | [第八章](../课程/08-视频世界模型与动作.md) |
| 消融 ablation | 改变或去掉一个因素，检查它的作用 | [第九章](../课程/09-评测与研究.md) |
| seed | 随机数生成的起点，用来复现一次随机实验 | 第一、九章 |
