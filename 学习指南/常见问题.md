# 卡住时，先看这里

[课程首页](../README.md) · [术语速查](术语速查.md)

## 不知道第一步该点什么

打开 [从这里开始](从这里开始.md)，做一小时的直线模型练习。随后继续第一章。资料库和研究计划等需要时再打开。

## 找不到章节正文

九章全部在 [课程目录](../课程/README.md)，首页也能直接点击。旧链接仍可打开，并指向对应中文章节。以前的编号中视频生成与视频世界模型顺序不直观，新目录已经按学习顺序排列。

## 数学公式看不懂

先代入一个数值例子，写出每个量是什么，再看一般公式。第一章的梯度先做直线练习，第二章的注意力先用两个向量，第四章的生成先用一维高斯。卡点是矩阵形状就回第一章，卡点是词义就查术语页。

## 不会 Python

先在 [第一个练习](../练习/01-线性回归/README.md) 做手算；再用第一章的 Python 前置练习学习变量、循环、函数和文件。已有代码可以先运行、改一个参数、看结果，逐步理解每一行。

## 没有 GPU

基础练习和三个专题实验都能用 CPU。视频章节先做预算、提示与评测设计；有设备后再运行完整模型。代码阅读、实验设计和实际生成要分别记录。

## 官方论文太多，而且大部分英文

先读本章的中文解释，再带着一个问题读指定部分。第一次找摘要、方法图和与你问题有关的一节。把不懂的公式记下来，回正文或基础教材补。第一遍不要求把资料库全部读完。

## 程序报错

先确认终端位于有 `README.md` 的课程根目录，再检查命令和 Python 版本。保留报错末尾几行、运行命令与输入参数；不要只换 seed 或删除所有输出。各练习说明页给出了应生成的文件。

## 程序跑完了，还是不知道看什么

打开对应练习说明，只回答该练习的问题：直线看参数与留出误差，行为克隆看闭环失败，生成看场误差与积分误差，世界模型看预测与控制代价。先把一项指标从原始数据核对一遍。

## 怎样知道可以去下一章

能用自己的话解释本章开头的完成标准，能完成关键练习，就可以继续。完整主线结束前补齐更多练习；已有基础用等价成果替代。记下仍不确定的地方，不需要把所有选读做完才前进。

## 想做研究，应该先选哪个模型

先做 [第一份实验报告](../示例/第一份实验报告.md)，练习只改变一个因素。能复核结果后，再去 [深入研究](深入研究.md) 选问题，按数据、设备和预算选择实际可运行的方法。
