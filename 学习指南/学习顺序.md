# 为什么按这个顺序学

[课程首页](../README.md) · [从这里开始](从这里开始.md)

默认顺序是：**基础 → 视觉 → 机器人 → 生成方法 → 机器人策略 → 世界预测 → 视频 → 视频与动作结合 → 研究。**

| 章节 | 先解决的问题 | 它为下一步提供什么 |
|---|---|---|
| [1 数学与深度学习](../课程/01-数学与深度学习.md) | 数据、参数、损失和梯度 | 看懂任何模型的训练过程 |
| [2 视觉与 Transformer](../课程/02-视觉与Transformer.md) | 图片、序列和注意力 | 看懂模型怎样处理图像与指令 |
| [3 机器人与控制](../课程/03-机器人与控制.md) | 坐标、动作、反馈和示教 | 知道模型输出怎样变成运动 |
| [4 扩散与 Flow Matching](../课程/04-扩散与FlowMatching.md) | 噪声怎样变成样本 | 理解连续动作和视频的生成方法 |
| [5 模仿学习与 VLA](../课程/05-模仿学习与VLA.md) | 从示范与语言得到动作 | 能比较策略，也理解策略的局限 |
| [6 世界模型与规划](../课程/06-世界模型与规划.md) | 预测行动后果，再选择动作 | 区分预测能力与实际控制收益 |
| [7 视频生成](../课程/07-视频生成.md) | 时间、压缩、条件和评测 | 理解视频预测使用的工具 |
| [8 视频世界模型与动作](../课程/08-视频世界模型与动作.md) | 视频与动作怎样连接 | 能分辨前沿路线的输入输出 |
| [9 评测与研究](../课程/09-评测与研究.md) | 用对照实验回答一个问题 | 开始自己的小研究 |

第四章先于第五章，是因为一些机器人策略用生成模型输出连续动作。第七章先于第八章，是因为要先知道视频怎样生成，再判断视频能不能指导行动。

第一遍按章学，无需自己拼前置关系。仅学一个方向时，使用 [专题学习](专题学习.md) 的路线。每章末尾都有下一章链接。

整套主线约 192 小时，按每周 8 小时安排为 24 周。时间包括讲解、指定阅读和基础练习；完整模型训练、全部选读和排障需要另外留时间。详见 [24 周安排](24周安排.md)。
