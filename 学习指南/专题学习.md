# 想重点学一个方向

[回到课程首页](../README.md)

刚开始接触机器学习时，先按首页的完整顺序。已经有基础，或明确只需要某个方向时，再使用下面的路线。

## 机器人怎样从示范学习

[1 数学与深度学习](../课程/01-数学与深度学习.md) → [2 视觉](../课程/02-视觉与Transformer.md) → [3 机器人与控制](../课程/03-机器人与控制.md) → [4 生成方法](../课程/04-扩散与FlowMatching.md) → [5 模仿学习与 VLA](../课程/05-模仿学习与VLA.md) → [9 评测与研究](../课程/09-评测与研究.md)。

先完成行为克隆实验，解释为什么示范误差小还会执行失败。然后比较动作块、离散动作和连续生成动作。更深入时，选 [机器人研究方向](深入研究.md)。

## 模型怎样预测世界并帮助决策

先完成上面的基础与策略内容，再读 [6 世界模型与规划](../课程/06-世界模型与规划.md) 和 [9 评测与研究](../课程/09-评测与研究.md)。已有控制与模仿学习经验，可用各章自测跳过熟悉部分。

先完成预测/规划实验，看一步误差、多步误差和实际代价有没有一致变化。若重点研究视频世界模型，再补 [7 视频生成](../课程/07-视频生成.md) 与 [8 视频世界模型与动作](../课程/08-视频世界模型与动作.md)。

## 视频怎样生成

[1 数学与深度学习](../课程/01-数学与深度学习.md) → [2 视觉](../课程/02-视觉与Transformer.md) → [4 生成方法](../课程/04-扩散与FlowMatching.md) → [7 视频生成](../课程/07-视频生成.md) → [9 评测与研究](../课程/09-评测与研究.md)。

先跑一维生成实验，分清训练误差和采样误差，再做视频预算与评测练习。机器人控制章节可以以后补；要把生成视频用于机器人行动时，补第三、五、六、八章。

## 怎样判断可以跳过一章

能独立完成该章的关键练习，并能解释它的完成标准，就可以跳过基础阅读。记得模型名字或读过摘要，还不足以替代练习。
