# 把九章放进 24 周

[回到课程首页](../README.md) · [第一次学习](从这里开始.md)

下面按每周约 8 小时安排：2 小时读本仓库讲解，2 小时读指定资料，3 小时练习，1 小时复盘。先照章节步骤做；遇到难点可以多用一周。不会 Python 时，在第一周前增加预备练习。

| 周 | 这周只推进这些内容 | 完成后留下什么 |
|---|---|---|
| 1 | [第一章](../课程/01-数学与深度学习.md)：Python、向量和最小直线模型 | 跑通或手算线性回归，解释参数与数据 |
| 2 | 第一章：损失、梯度、有限差分 | 一次梯度核对，知道学习率在改什么 |
| 3 | 第一章：概率、采样与条件均值 | 高斯采样统计，解释两个动作取均值的问题 |
| 4 | 第一章：训练循环与数据划分 | 一份训练/验证/测试划分说明 |
| 5 | [第二章](../课程/02-视觉与Transformer.md)：图像特征、patch、注意力 | 注意力算例与中间结果 |
| 6 | 第二章：位置与多模态连接 | 一张图片/文本/动作输入输出图 |
| 7 | [第三章](../课程/03-机器人与控制.md)：坐标、运动学、控制 | 坐标算例与动作单位说明 |
| 8 | 第三章：示教、仿真、任务与划分 | 按轨迹/场景划分的例子 |
| 9 | [第四章](../课程/04-扩散与FlowMatching.md)：DDPM、噪声与 score | 一张训练样本示意 |
| 10 | 第四章：Flow Matching、Euler 采样 | 一维实验的输出与误差解释 |
| 11 | 第四章：条件与网络结构 | 能分清目标、骨干与采样器 |
| 12 | [第五章](../课程/05-模仿学习与VLA.md)：行为克隆与覆盖 | 同分布误差和闭环失败对照 |
| 13 | 第五章：DAgger、ACT、Diffusion Policy | 动作表示和执行节奏对照 |
| 14 | 第五章：RT-2、OpenVLA、π0 | 三种模型的输入输出图 |
| 15 | [第六章](../课程/06-世界模型与规划.md)：状态、RSSM、Dreamer | 有观测和想象时的数据流 |
| 16 | 第六章：表征预测与动作条件 | 世界模型实验的一步/多步误差 |
| 17 | 第六章：开环与滚动规划 | 控制代价、失败和计算次数 |
| 18 | [第七章](../课程/07-视频生成.md)：压缩、时空结构与条件 | 两个视频 token 预算 |
| 19 | 第七章：视频质量和控制评测 | 12 条提示及判断标准 |
| 20 | [第八章](../课程/08-视频世界模型与动作.md)：三种视频/动作路线 | 三张方法流程图 |
| 21 | 第八章：选一篇论文对照 | 方法、证据和适用范围的笔记 |
| 22 | [第九章](../课程/09-评测与研究.md)：选一个小问题 | 先写预期、对照和指标 |
| 23 | 第九章：运行与分析 | 所有种子的结果表，保留失败 |
| 24 | 第九章：复跑与报告 | 别人能重跑的一份小实验 |

每周 4 小时，可以把表中一周拆成两周；已有基础可以缩短熟悉章节。时间是规划参考，继续学习以你能解释和完成练习为准。

第一遍优先完成每章开头的关键练习。完整主线结束前，再补正文中尚未完成的练习。只学专题时按 [专题路线](专题学习.md) 学相应章节；深入研究另安排 [12 周](深入研究.md)。
