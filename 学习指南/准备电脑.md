# 准备电脑：先跑最小练习

[课程首页](../README.md) · [第一个练习](../练习/01-线性回归/README.md)

阅读和手算可以直接在 GitHub 上做。运行本仓库的基础练习与三个专题实验，只需要 Python 3.11/3.12 和 CPU。

## 第一步：检查 Python

Windows 使用 Git Bash，执行：

```bash
python --version
```

显示版本号就继续。若提示找不到命令，先按 [Python 官方 Windows 文档](https://docs.python.org/3/using/windows.html) 配置 Python；若本机使用 `py` 启动器，后面的 `python` 可换成 `py`。此时先不用安装 PyTorch。

## 第二步：找到本地课程目录

你已经有本地课程时，进入它的文件夹。看到 `README.md`、`课程`、`练习`、`labs`，就到了仓库根目录。

需要自行下载时，在 GitHub 点 **Code → Download ZIP**，解压到 E 盘自己选的文件夹。也可以用 Git；下面以 E 盘的 `AI学习` 为例，仅在还没有本地副本时执行：

```bash
mkdir -p /e/AI学习
cd /e/AI学习
git clone https://github.com/Charon621/embodied-ai-learning.git
cd embodied-ai-learning
```

已有同名目录就直接进入，不要重复 clone。Linux/macOS 在自己的目录解压或 clone，再运行相同的 Python 命令。

## 第三步：只跑第一个练习

```bash
python 练习/01-线性回归/train.py
```

终端会显示初始误差、学到的 `w、b` 和留出误差。结果写入 `outputs/linear-regression/`。回到 [练习说明](../练习/01-线性回归/README.md) 看怎么解释。下一步继续 [第一章](../课程/01-数学与深度学习.md)。

## 学到相应章节，再增加工具

| 你现在做什么 | 需要什么 |
|---|---|
| 读课文、手算、基础练习、三个专题实验 | 浏览器；运行代码时用 Python 与 CPU |
| 做小型神经网络练习 | 独立虚拟环境，按 [PyTorch 官方选择器](https://docs.pytorch.org/get-started/locally/) 安装 |
| 运行 MuJoCo/LIBERO 或完整 VLA、视频模型 | 按选定项目的官方版本准备环境、数据和硬件 |

外部模型需要的显存取决于任务、权重、分辨率、精度与加载方式。先看对应官方说明再决定是否运行。仿真器、机器人策略和视频模型分开建环境，避免一次混装所有依赖。

本地练习输出放 `outputs/`，个人笔记放 `my-progress/`，两者不会被 Git 提交。可选模型下载时也指定 E 盘的数据目录和缓存；本课程的基础脚本不会触发下载。完整模型与真机实验的已验证范围见 [验证记录](验证记录.md)。
