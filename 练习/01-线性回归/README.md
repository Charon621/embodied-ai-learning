# 让程序学会一条直线

[第一章](../../课程/01-数学与深度学习.md) · [课程首页](../../README.md)

目标：看见参数怎样更新，理解“训练”在做什么。先做手算，再运行完整程序。预计第一次用 30–45 分钟。

## 先手算一次更新

数据是 `(x,y)=(0,-1)、(1,1)`。模型为 `预测=w*x+b`，起初 `w=0、b=0`。

| 样本 | 预测 | 预测减真实值 | 平方误差 |
|---|---:|---:|---:|
| x=0，y=-1 | 0 | 1 | 1 |
| x=1，y=1 | 0 | -1 | 1 |

平均损失为 1。按照第一章公式，`dL/dw=-1、dL/db=0`。学习率设为 0.1，更新后 `w=0.1、b=0`；两条预测成为 0、0.1，新的平均损失是 `(1+0.9²)/2=0.905`。

一次更新没有得到答案，但误差减小了。继续更新，程序逐步靠近能解释数据的参数。

## 跑一次完整练习

代码在 [train.py](train.py)。它生成 100 条带少量噪声的数据，规律是 `y=2x-1`，划分为 60 条训练、20 条验证、20 条测试。只有训练数据参与参数更新。

在有 `README.md` 的仓库根目录执行：

```bash
python 练习/01-线性回归/train.py
```

不需要第三方包。终端会显示初始误差、学到的参数、三组误差、梯度核对结果和输出位置。学到的参数应接近 `w=2、b=-1`，噪声使它们通常不会正好相等。

## 跑完看哪三个文件

| 文件 | 你应该看什么 |
|---|---|
| `outputs/linear-regression/metrics.json` | 初始误差、最终参数、三个集合的误差 |
| `outputs/linear-regression/history.csv` | 每十步的参数与训练/验证误差怎样变化 |
| `outputs/linear-regression/data.csv` | 一条具体数据的真实值和预测值差多少 |

JSON 中 `gradient_check.passed` 表示手推梯度和有限差分相符；它检查求导，不等于模型已经学会。最终误差才回答拟合结果怎样。

## 再只改一个数

把训练步数从 500 改成 10，输出另存一个目录：

```bash
python 练习/01-线性回归/train.py --steps 10 --output-dir outputs/linear-short
```

比较两次的参数和误差。然后尝试改变学习率，观察变化；不要使用测试集选择学习率。

## 完成标准

能手算上述更新，指出哪些数据用于训练，并用 `history.csv` 解释“参数在变，误差也在变”。回到 [第一章](../../课程/01-数学与深度学习.md) 继续概率、训练循环与数据划分。
