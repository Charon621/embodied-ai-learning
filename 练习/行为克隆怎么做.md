# 行为克隆：误差小，为什么执行还会失败？

[第五章](../课程/05-模仿学习与VLA.md) · [课程首页](../README.md)

先想象只在目标附近练习一个动作。从较远位置开始执行，可能来到示范里没有出现过的状态。这个小实验把现象变成可以查看的数字。

## 先跑一次

```bash
python labs/01_behavior_cloning.py --seed 7 --output-dir outputs/bc
```

程序比较专家、只看窄范围示范的策略，以及增加访问状态标签后的策略。生成 `metrics.json`、`rollouts.csv`、`rollout.svg`。

## 跑完先看三项

| JSON 中的位置 | 含义 | seed 7 的教学参考 |
|---|---|---|
| `iid_action_mse.bc` | 相似状态上的独立动作误差 | 约 0.0000454 |
| `closed_loop.bc.mean_state_cost` | 真正连续执行后的平均状态代价 | 约 139.946 |
| `closed_loop.feedback.mean_state_cost` | 加入访问状态标签后，连续执行的代价 | 约 4.004 |

本例的专家代价为 4。它显示：相似状态上的动作误差很小，仍不能保证从远处执行成功。这里的数值来自本仓库固定配置；没有机器人实验。

打开 `rollout.svg` 看一个起点的过程，再到 CSV 找同一轨迹。图是一条例子，平均代价来自全部 8 个起点。

## 用三句话解释结果

1. 为什么连续执行会改变接下来访问的状态？
2. 反馈版本看到了什么新的数据？查询了多少标签？
3. 如果给离线版本同样多的广范围标签，结果可能怎样？当前比较能否回答？

反馈版本增加了标签数量，不能把改善全部归因于“交互比离线好”。这个教学模型使用已知二次特征和岭回归，没有实现完整 DAgger、摄像头或 VLA。

更完整的方程、失败惩罚和输出说明在 [实验说明](../labs/README.md)。解释上述问题后，继续 [第五章](../课程/05-模仿学习与VLA.md) 的动作表示和 VLA。
