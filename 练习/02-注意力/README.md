# 看清一次注意力计算

[第二章](../../课程/02-视觉与Transformer.md) · [课程首页](../../README.md)

目标：知道注意力权重从哪里来、怎样加权读取信息。第一次约 30 分钟。

## 手算两个候选信息

查询 `Q=[1,0]`；两个 key 为 `[1,0]、[0,1]`；两个 value 为 `[2,0]、[0,2]`。

1. Q 与两个 key 点积，得到 `1、0`。
2. 除以 `sqrt(2)`，得到约 `0.7071、0`。
3. 用 softmax 归一化：权重约为 `0.6698、0.3302`。
4. 将两个 value 加权相加：结果约为 `[1.3395,0.6605]`。

查询和 key 用于决定读取权重，value 是被读取的内容。屏蔽第二个 key 后，权重成为 `1、0`，输出 `[2,0]`。

## 用程序核对

代码在 [attention.py](attention.py)，在仓库根目录运行：

```bash
python 练习/02-注意力/attention.py
```

终端显示刚才的两种结果，还会显示三个 token 的因果 mask：第一行只读第一个 token；第二行读前两个；第三行读全部三个。

结果在 `outputs/attention/result.json`。重点看 `weights` 和 `output`。这是单头注意力的算术例子，没有训练 Transformer。

## 再算图像的 token 数

224×224 图像切成 16×16 的块，得到 `14×14=196` 个 token；512×512 得到 `32×32=1024` 个。16 帧的前一种图像，若全部拼成时空序列，得到 `16×196=3136` 个。

程序还生成 `token-budget.csv`，比较全注意力与分解时空注意力的矩阵项数。它只是结构上的数量估计，没有测量显存或运行速度，也不包括 CLS token。
