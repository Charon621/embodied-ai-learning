# Lab 03｜学到的动力学、预测误差与闭环规划

关联 [M06](../docs/modules/06-latent-world-models.md) 和 [M07](../docs/modules/07-video-world-models-and-wam.md)。这个实验只用 Python 标准库和 CPU，不联网、不下载模型或数据、不安装第三方依赖。它帮助理解世界模型进入控制环后会发生什么；**没有实现 Dreamer、RSSM、JEPA、视频编码器或真实机器人**。

## 运行

使用 Python 3.10 或更高版本，在仓库根目录运行。Windows 默认用 Git Bash；若 `python` 不在 PATH 中，请替换为本机 Python 可执行文件路径。

```bash
python labs/03_world_model_planning.py --seed 17 --output-dir outputs/03-world-model
```

脚本默认每种控制情景运行 8 对独立初态，控制长度为 24 步。参数 `--episodes 1..64` 控制配对试验数量，`--horizon 8..48` 同时改变总执行长度和初始计划长度。例如另一组 seed：

```bash
python labs/03_world_model_planning.py --seed 42 --output-dir outputs/03-world-model-seed42
```

输出目录只放本实验的生成文件。重复运行会覆盖该目录中同名生成文件，报告另存为 `world-model-report.md`。

## 环境与模型

状态是位置 `p` 和速度 `v`，动作 `a∈[-1,1]`。真实环境采用下面的确定性动态；研究者知道方程，拟合器只看到采集的状态动作转移：

```text
gain(p) = 0.20 + 0.10*tanh(max(abs(p)-2, 0))
v_next = 0.90*v + gain(p)*a - 0.015*sin(p) + impulse
p_next = p + v_next
```

训练数据由 64 条、每条 30 步的探索轨迹组成，采集策略让状态主要停留在原点附近。使用岭项很小的最小二乘拟合：

```text
v_next_hat = cp*p + cv*v + ca*a + c0
p_next_hat = p + v_next_hat
```

这个线性模型无法完整表达 `sin(p)` 和分布外的动作增益变化，误差是明确的模型类别限制。额外建立 `biased` 模型，将学到的动作系数乘 `0.65`，截距加 `0.035`，模拟人为系统性误差；它没有重新拟合或使用测试标签。

训练、分布内 holdout 和分布外 holdout 使用独立 seed 与整条轨迹，不拆散相邻帧后随机混入两个集合。每个 holdout 有 32 条、每条 24 步；分布外采集在 `p≈3.5` 附近。真实采集范围写在 `metrics.json.training_range`，应先查看范围再使用“分布外”一词。

## 两种预测评测

一步预测每次使用真实前态，覆盖 holdout 的全部 768 个转移。自由 rollout 每条 holdout 仅从第一步真实状态开始，接下来把预测状态送回模型，同时输入该轨迹记录的动作；报告 1–20 步误差。因此一步指标与自由曲线的第 1 点**采用不同样本集合**，不要要求它们数值相等。

位置与速度误差分别计算 RMSE，综合状态 RMSE 为：

```text
sqrt(mean((position_error² + velocity_error²) / 2))
```

这里的状态和单位是人工设置的，因此等权平均仅适用于本 toy。真实机器人需要先讨论单位、量纲、归一化及哪些状态对任务重要。

## 两种控制器

两者使用同一个拟合模型、动作约束、二次目标和坐标下降求解器：

```text
sum_t [q_t*(p_next-goal)² + 0.10*v_next² + 0.03*a²]
q_t = 1，最后一步 q_t = 4
```

- `open_loop`：从初态一次规划全部 24 步，随后执行完整动作序列；新观测仅用于记录实际轨迹，不改变动作。
- `receding_horizon`：每步从真实观测重新规划余下步数，只执行首个动作。初始目标与首轮求解和开环完全相同，计划范围逐步减短，不更新模型参数。

测试四种情景：分布内基线；第 8 步外加 `0.45` 速度冲击；分布外初态 `p≈3.6`；人为偏差模型。冲击不告知规划器，同一对控制器使用相同初态和冲击。结果同时报告计划调用数和求解器 projected gradient 残差，防止把反馈计算增加或求解不充分藏起来。

## 输出及怎样复核

| 文件 | 内容 |
|---|---|
| `metrics.json` | 配置、训练范围、模型系数、一步/多步误差、配对控制统计、限制 |
| `train.csv`、`holdout.csv` | 原始转移与整条轨迹编号，验证划分和拟合来源 |
| `prediction_errors.csv` | 按 split、模型和 horizon 汇总的误差 |
| `predictions.csv` | 每个自由 rollout 时刻的真实值、预测值与误差 |
| `control_summary.csv` | 每条控制轨迹的代价、末端误差、计划调用数和求解残差 |
| `trajectories.csv` | 实际执行、动作、冲击、下一状态、模型一步预测及每步代价 |
| `prediction_errors.svg` | 分布内/外自由 rollout 误差曲线 |
| `control_trajectories.svg` | 每种情景第 0 对试验的实际位置与目标，仅为示例轨迹 |

打开 SVG 即可观察曲线。控制统计用全部 8 对轨迹，不能用示例图的一对轨迹代替统计。

## 已运行的教学基线

2026-10-11 使用此版本脚本、`seed=17`、8 对试验、24 步实际运行得到如下结果，数值只说明本 toy。另一组 `seed=42` 也完整运行成功；不是跨平台或真实模型验证。

| 预测指标 | 分布内 fitted | 分布外 fitted |
|---|---:|---:|
| 一步状态 RMSE | 0.000191 | 0.066394 |
| 20 步自由 rollout 状态 RMSE | 0.003604 | 2.903237 |

| 情景 | 开环平均代价 | 滚动规划平均代价 |
|---|---:|---:|
| 分布内基线 | 6.247767 | 6.197708 |
| 未知速度冲击 | 225.878783 | 6.977579 |
| 分布外初态 | 51.171901 | 46.134581 |
| 人为模型偏差 | 276.118306 | 6.551808 |

这里的滚动规划每条轨迹调用 24 次规划，开环只调用 1 次，**不是相同推理预算比较**。所有模型的坐标下降最多执行 160 轮，基线最大求解残差约 `0.00155`，应报告优化近似的影响。

另一个值得分析的现象：人为偏差模型在分布外 20 步误差约 `0.991087`，反而低于 fitted 的 `2.903237`，但它的一步误差更大。错误可能暂时相互抵消，单条长程指标不能证明模型更准确，也不能强行要求所有“偏差”使所有指标变坏。

已核查：同 seed 重跑的 9 个文件逐字节一致；从 `predictions.csv` 独立重算分布外 20 步状态 RMSE；从 `trajectories.csv` 独立重算一条滚动规划轨迹代价；两个 SVG 均为有效 XML，并实际渲染检查曲线与文字布局。复现实验结果与复现论文性能是不同层级。
