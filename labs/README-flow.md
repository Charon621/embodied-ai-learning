# 实验 02：学到一维速度场，再把噪声运输成目标分布

对应 [第4章](../课程/04-扩散与FlowMatching.md)。只用 Python 标准库和 CPU，不联网、不下载数据/权重、不安装库、不调用 API。需要 Python 3.8 或更高版本。仓库根目录运行：

```bash
python labs/02_flow_matching.py --output-dir outputs/02-flow --seed 2026
```

## 你实际学了什么

源分布是 `N(0,1)`，目标分布是 `N(2,0.5²)`。训练每个时间节点时，独立采样端点对 `(x0,x1)`，构造 `xt=(1-t)x0+t*x1`、监督速度 `u=x1-x0`。模型是 `v(x,t)=a(t)*x+b(t)`：每个时间节点用最小二乘从抽样训练对学习两个系数，节点之间线性插值。这个分布的条件均值确实是仿射形式，所以选用它容易解释；实验没有训练神经网络。

采样从另一随机流的独立噪声出发，用 Euler 更新 `x <- x+dt*v(x,t)`。解析高斯速度只用于独立参考：它不参与拟合。脚本比较三类误差：训练得到的场对解析场的速度 RMSE；同一步数下学习场与解析场输出差异；解析场 Euler 输出与精确终点 `2+0.5*x0` 的差异。最后一种能直接检验积分误差是否随加密步数下降。

条件回归的训练 loss 含有不可约条件方差，不应要求归零。终点的样本均值、标准差也含有限样本误差。输出中的 `moment_matched_gaussian_w2` 使用样本矩构造高斯，再计算其与目标高斯的 W2；它不是任意两个经验分布的 W2，不能拿来声称高维生成质量。

## 输出与判读

默认输出目录为 `outputs/02-flow`。每次在相同目录运行会更新同名产物；需要保存不同配置时用不同 `--output-dir`。

| 文件 | 内容 | 检查点 |
|---|---|---|
| `metrics.json` | 配置、种子、基线、8/32/128 步结果、验证与边界 | 学习场应优于恒等基线；解析场积分误差随步数增加下降 |
| `field.csv` | 学到的 `a,b`、训练 MSE、解析系数 | 学到系数与解析系数接近，但不完全相同 |
| `samples.csv` | 独立初始样本、学习场终点、精确参考终点 | 可自行重算均值、标准差，核对 JSON |
| `flow.svg` | 初始/终点直方图、目标密度、8 条轨迹 | 用浏览器打开，不需要绘图库 |

`checks_passed` 为 true 且进程退出码为 0，表示这套玩具实验的检查通过；失败时退出码为 1，仍保留产物供诊断。检查验证数值有限、运输优于恒等基线、终点矩误差与速度误差，以及解析场的积分收敛。它们不证明真实视频模型有效。

默认阈值：最大步数结果均值绝对误差 `<0.08`，标准差误差 `<0.06`；独立点速度 RMSE `<0.10`。更改训练量、步数或样本数可能使检查失败，这是需要分析的结果。积分步数自动去重、从小到大排列；检查比较最小与最大步数的解析场误差。只有一个步数时无从检查步数收敛，该项记录为 `null` 并列入 `skipped_checks`，不参与通过计算；报告须注明未做收敛比较。

## 已运行的本地参考

核验日期：2026-10-11。默认配置 `seed=2026`、41 个节点、每节点 6000 对、2048 个独立采样、128 步下，学习场输出均值约 `1.98695`、标准差约 `0.48383`；速度 RMSE 约 `0.01386`。解析场 128 步终点 RMSE 约 `0.00567`；所有默认检查通过。这只是该固定配置的一次本地运行，不是论文复现或性能排名。自测使用解析分布与精确流终点作数学参照，没有用另一份同构实现互相验证。

## 练习与验收

1. 不看代码，推导 `mt=2t`、`qt=(1-t)²+0.25t²` 与 第4章 的条件速度公式。
2. 重算 `samples.csv` 的终点矩，并说明它与理论目标不同的两个原因。
3. 固定训练场，比较 `--steps 8,32,128,512`；当积分误差越来越小时，学习误差是否也同步下降？给出数据。
4. 另用 `--seed 0` 和 `--seed 7`，报告全部结果，解释种子变化来自训练抽样和评估抽样两部分。
5. 交一页报告加四个产物，注明玩具模型、无神经网络、无图像/视频、无物理因果结论。

可调整参数示例：

```bash
python labs/02_flow_matching.py --output-dir outputs/02-flow-low --seed 2026 --train-per-knot 500 --samples 512 --steps 8,32,128
python labs/02_flow_matching.py --output-dir outputs/02-flow-fine --seed 2026 --steps 8,32,128,512
```

第一条可能无法满足默认质量阈值，保留并解释，不是脚本崩溃。进阶时把目标变为双峰：仿射模型只会匹配有限的形状信息，不能通过增加 Euler 步数克服表示能力限制。先写出更合适的非线性场、独立检验和失败标准，再考虑框架或 GPU。
