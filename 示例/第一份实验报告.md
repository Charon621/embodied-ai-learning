# 第一份小报告：采样步数增加，什么误差变小？

[第九章](../课程/09-评测与研究.md) · [课程首页](../README.md)

这是已经填写的教学报告示例，数据来自 [首次实测摘要](../examples/baseline-metrics.json)。你可以先复跑，再用同样结构记录自己的实验。

## 1. 我的问题

固定学到的速度场，Euler 采样从 8 步增加到 32、128 步后，积分误差和学习场误差会不会一起减小？

**先写预期**：更细步长应减少这个解析参考问题中的积分误差；学到的场已经固定，因此不能把采样更细说成模型重新学得更好。

## 2. 怎么比较

运行三个种子，每次输出目录不同：

```bash
python labs/02_flow_matching.py --seed 7 --steps 8,32,128 --output-dir outputs/report-seed7
python labs/02_flow_matching.py --seed 19 --steps 8,32,128 --output-dir outputs/report-seed19
python labs/02_flow_matching.py --seed 42 --steps 8,32,128 --output-dir outputs/report-seed42
```

同一 seed 的这三个步数使用同一训练场和同一评估样本。比较时保持节点数、训练样本量、源/目标分布等默认设置不变，只改变积分步数。

两个指标分别是：

- **解析场 Euler 终点与精确终点的 RMSE**：隔离积分误差。
- **学习场与解析场在同一步数下的输出 RMSE**：观察固定学习场带来的差异。

更完整定义见 [实验说明](../labs/README-flow.md)。

## 3. 全部结果

| seed | 步数 | 解析场积分误差 | 学习场与解析场的输出差异 |
|---|---:|---:|---:|
| 7 | 8 | 0.083729 | 0.001487 |
| 7 | 32 | 0.022242 | 0.001421 |
| 7 | 128 | 0.005655 | 0.001478 |
| 19 | 8 | 0.086299 | 0.003898 |
| 19 | 32 | 0.022924 | 0.001344 |
| 19 | 128 | 0.005828 | 0.001198 |
| 42 | 8 | 0.085401 | 0.004255 |
| 42 | 32 | 0.022686 | 0.003709 |
| 42 | 128 | 0.005767 | 0.003816 |

## 4. 结果支持什么

这三个 seed 中，解析参考的积分误差随步数增加下降。固定学习场的输出差异没有全部单调下降：seed 7 和 42 从 32 到 128 步略增。因此，采样步数与学习误差不能混为一谈。

这是受控一维问题中的观察，没有图像、视频或真实机器人，也没有证明所有采样器或生成模型都有相同规律。更多采样步数还增加计算，需要另测真实任务的时间与质量。

## 5. 下一步只改一个因素

增加 512 步，继续固定训练设置与评估样本，观察收益何时减弱。或者另做一组降低训练样本量的实验；将它作为新的自变量，不与步数变化混进同一个对照。
