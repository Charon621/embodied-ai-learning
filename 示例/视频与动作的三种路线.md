# 同样用了视频，动作可能来自不同地方

[第八章](../课程/08-视频世界模型与动作.md) · [课程首页](../README.md)

下面是机制示意，帮助你带着问题读论文。具体输入、实现和实验结论，仍须按对应版本核对。

## 路线一：先画出计划，再把计划变成动作

```mermaid
flowchart LR
    A[当前观察与目标] --> B[生成计划视频]
    B --> C[逆动力学模型]
    C --> D[执行动作]
```

预测的相邻画面提供“想怎样变化”，逆动力学模型估计“要怎样行动才能产生变化”。阅读 [UniPi](https://arxiv.org/abs/2302.00111) 时，找出视频计划与动作模型分别怎样训练。

要问：生成计划是否能由当前机器人实现？把视频变成动作时用了哪些交互数据？

## 路线二：给模型一个候选动作，看未来会怎样

```mermaid
flowchart LR
    A[当前观察和候选动作] --> B[动作条件预测器]
    B --> C[预测未来并按目标评分]
    C --> D[选择动作并执行]
```

动作先进入前向模型，预测用于比较候选。新的观测到来后可再规划。预测可以发生在表征空间，例如 [V-JEPA 2-AC](https://arxiv.org/abs/2506.09985)；并不一定生成给人看的像素视频。

要问：目标怎样评分？搜索花了多少计算？观测多久更新一次？

## 路线三：把视频与动作一起建模

```mermaid
flowchart LR
    A[当前观察与目标等条件] --> B[联合视频和动作的模型]
    B --> C[预测视频与动作]
    C --> D[动作进入执行环]
```

联合模型同时处理未来视频与动作。读 [DreamZero](https://arxiv.org/abs/2602.15922) 时，核对条件、联合训练、采样与执行方式；“同时输出”还不足以证明真实控制有效。

要问：两种输出如何对齐时间？执行用了几步动作？有无真实机器人或仿真闭环证据？

## 做一张自己的对照表

| 检查项 | 你应在论文里找到什么 |
|---|---|
| 动作从哪来 | 逆动力学、候选搜索，还是模型直接生成 |
| 未来怎样表示 | 像素、压缩表示，还是任务相关表征 |
| 执行怎样反馈 | 多久重新观察，多久重新生成或规划 |
| 证据支持到哪 | 视频质量、预测误差、仿真控制或真实硬件表现 |

先选一篇做完整对照，随后回 [第八章](../课程/08-视频世界模型与动作.md) 阅读其余路线。
