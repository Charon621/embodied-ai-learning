# 带着一个问题读论文

[课程首页](../README.md) · [第四章](../课程/04-扩散与FlowMatching.md)

以 [Flow Matching for Generative Modeling](https://arxiv.org/abs/2210.02747) 为例。第一次的目标是弄清“训练与采样各在做什么”，不必逐句翻译全文。

## 阅读顺序

1. **摘要与引言**：记下要解决什么问题，先圈出不懂的词。
2. **方法中的训练目标**：找到模型预测的量和监督目标；回第四章核对速度场。
3. **采样过程**：查清训练完后怎样从初始噪声走到结果。
4. **实验与限制**：看看哪些数据和设置支持哪些结论；数值比较必须带版本与协议。

## 这次的笔记可以只写这些

| 问题 | 初步理解 |
|---|---|
| 模型学什么 | 随时间与位置变化的速度场 |
| 训练时做什么 | 从规定的路径构造回归目标 |
| 生成时做什么 | 使用学到的场求解运输过程 |
| 本仓库做了什么 | 一维高斯路径的仿射回归与 Euler 采样 |
| 还没有做什么 | 神经网络与论文中的大规模生成结果复现 |

读完用自己的话回答：**为什么训练使用回归，而采样需要积分？** 回答不清，回到 [实验说明](../labs/README-flow.md)，把训练样本和一次 Euler 更新各写一遍。

熟练以后再用 [论文笔记模板](../templates/paper-card.md) 扩充公式、数据、实验和疑问。没有核对的内容写“待核对”，不要把摘要理解写成全文验证。
